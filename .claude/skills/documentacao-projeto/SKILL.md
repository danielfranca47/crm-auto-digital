# Documentação do projeto

Identifica o caso, lê **só** a referência dele e segue-a até ao critério de conclusão dela.

| Caso | Sinal no pedido | Referência |
|---|---|---|
| Escrever para agentes | criar ou editar uma skill, um comando slash, o CLAUDE.md ou um doc que eles apontam; encurtar uma descrição | [references/escrever-para-agentes.md](references/escrever-para-agentes.md) |
| Registar uma decisão | "porque é que ficou assim?", escolher entre abordagens, mudar algo caro de reverter, graduar uma implementação | [references/registar-decisoes.md](references/registar-decisoes.md) |
| Auditar o CLAUDE.md | "audita / revê / melhora o CLAUDE.md", o CLAUDE.md parece longo ou desatualizado | [references/auditar-claude-md.md](references/auditar-claude-md.md) |

Os casos combinam-se. Por exemplo, a auditoria propõe alterações ao CLAUDE.md, que se escrevem com as
regras de "escrever para agentes". Nesse caso, lê as duas referências.
