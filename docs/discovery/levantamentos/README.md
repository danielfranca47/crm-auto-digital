# Levantamentos

Material bruto que dá origem a investigações de discovery: conversas com outras
IAs ou consultores, relatórios de testes, feedback de clientes, análises de
concorrentes.

- Nome: `AAAA-MM-DD-<tema>.<ext>` (data em que entrou no repositório).
- Guardado **como veio** — não editar o conteúdo original; a análise vive nas
  investigações (`docs/discovery/<slug>.md`), que citam o levantamento em "Origem".
- Um levantamento pode gerar várias investigações; uma investigação aponta para
  um levantamento.
- Não guardar aqui dados sensíveis de clientes (telefones, conversas reais com
  nomes) — anonimizar antes.
