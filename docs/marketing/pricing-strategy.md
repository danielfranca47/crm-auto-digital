## DIAGNÓSTICO DE PRICING ATUAL

### Problemas Críticos Identificados

```
PROBLEMA 1: Confusão de preço na mesma página
  → Growth aparece por R$297 na tabela de planos
  → Growth aparece por R$147 na seção "Preço de Fundador"
  → Depois vira R$197 "para sempre"
  → Visitante não sabe quanto vai pagar = zero conversão

PROBLEMA 2: Âncora de valor fraca (R$1.735)
  → Valores internos somados: R$997 + R$297 + R$197 + R$147 + R$97
  → O cliente não sabe o que é R$997/mês para "Lara 24/7"
  → Âncora precisa ser baseada em alternativas de mercado reais

PROBLEMA 3: Start R$97 barato demais para o que entrega
  → CRM Kanban + IA 24/7 + qualificação por R$97/mês
  → Cria percepção de "se é tão barato, deve ser fraco"
  → Não resiste à comparação com SDR humano

PROBLEMA 4: Diferenciação por volume, não por caso de uso
  → SDR / Closer / Híbrido não aparecem na estrutura de planos
  → Planos diferenciam apenas conversas/mês — commodity
  → A especialização dos agentes é o maior diferencial — não está precificada
```

## VALUE ASSESSMENT — QUANTO A LARA REALMENTE VALE

### Dimensão Financeira: ROI por Agente

#### Agente SDR (Alto Ticket)

```
Ticket médio do cliente SDR: R$3.000 – R$15.000
Leads/mês no Growth: 500 conversas
Taxa de conversão humana sem follow-up sistemático: ~5%
Taxa de conversão com SDR Lara (follow-up automático): ~10-15%

Cenário conservador:
  100 leads/mês
  5% → 10% de conversão = +5 vendas/mês
  Ticket médio: R$3.000
  Receita adicional: R$15.000/mês

Custo da Lara Growth: R$297/mês
ROI: R$15.000 / R$297 = 50x no cenário conservador

Alternativa: SDR humano
  Salário + encargos: R$2.500 – R$4.500/mês
  Trabalha 8h/dia, 5 dias/semana
  Sem follow-up 24/7, sem CRM integrado

→ Comparação honesta: R$297 vs R$3.500/mês = 11x mais barato
→ Posicionamento: "Seu SDR custa R$3.500/mês. A Lara custa R$297."
```

#### Agente Closer (Baixo Ticket)

```
Ticket médio do cliente Closer: R$97 – R$997
Leads/mês típicos: 100–500
Taxa de recuperação de carrinho abandonado: 20-40%

Cenário conservador:
  200 leads/mês
  10% extra convertidos pelo follow-up automático = 20 vendas
  Ticket médio: R$300
  Receita adicional: R$6.000/mês

Custo da Lara Growth: R$297/mês
ROI: R$6.000 / R$297 = 20x

Alternativa sem Lara:
  Perde ~30% dos leads que não responde no mesmo dia
  Não faz follow-up em 70% dos casos por esquecimento

→ "1 venda extra por mês paga a Lara inteira."
```

#### Agente Híbrido Agendador (Serviços)

```
Custo de recepcionista: R$1.500/mês + R$700 encargos = R$2.200/mês
  → trabalha 44h/semana, sem 24/7, sem follow-up automático

Sessão do profissional: R$200 – R$800
Ausências por falta de confirmação: 10-20% das sessões
Com Lara (confirmação + follow-up): redução de 80% das ausências

Cenário conservador — psicóloga com 20 sessões/semana:
  4 ausências/semana = 16/mês → R$3.200/mês perdidos
  Com Lara: 3-4 ausências eliminadas = R$2.400/mês recuperados

Custo da Lara Growth: R$297/mês
ROI: R$2.400 / R$297 = 8x

→ "Sua recepcionista custa R$2.200/mês. A Lara custa R$297 — e trabalha 24/7."
```
